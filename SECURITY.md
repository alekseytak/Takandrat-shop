# Security

## Объявление о раскрытии
Tak and Rat Shop обязуется обрабатывать все секреты и личные данные с особой осторожностью. В случае обнаружения уязвимости в нашей инфраструктуре, пожалуйста, свяжитесь с нами безопасным каналом (предпочтительно через зашифрованное средство связи).

## Контакты безопасности (создатель)
- Email: [Создано Kilo для Takandrat-shop](mailto:?subject=Security%20Issue%20Report)
- GitHub: [Создано Kilo](https://github.com/Kilo-Org/kilocode)

## Политика конфиденциальности
- Не коммитьте реальные секреты в репозиторий
- Используйте Vercel Environment Variables и Supabase Secrets для хранения токенов, карт и кошельков
- Используйте .githooks/pre-commit для предотвращения случайного коммита секретов
- Перекручивайте историю git, если ключ был опубликован
- Регenerate environment variables после обнаружения компрометации

## Документация по безопасности
- README.md: Инцидентный ответ

## Уведомления о безопасности
- Следите за обновлениями README.md и SECURITY.md
- Документация по инцидентам: README.md § Incident Response

## Предотвращение
- Используйте pre-commit хук для блокировки секретов на уровне кода
- Редактируйте .gitignore для защиты дополнительных секретов
- Регулярно проверяйте commits history на предмет секретов
- Используйте git-filter-repo для перекручивания истории в случае компрометации
